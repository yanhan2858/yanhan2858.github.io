XHTTP CDN Review: Personal Tests of Multiple CDNs

AI translation notice:
This English version was translated from the original Chinese article with AI assistance. The original Chinese version is authoritative; please refer to it if any wording is unclear.

This article is an informal account of personal experience, provided for reference only. Please comply with the laws and regulations in your area. Please keep the article's timeliness in mind while reading.

XHTTP can use POST and GET to pass through certain CDNs for data transmission. This makes it possible to use a CDN as a reverse proxy for a node. Because CDNs behave differently, being able to pass through XHTTP does not necessarily mean a good user experience.

There are three prerequisites for running XHTTP through a CDN:

The CDN supports adding a third-party origin server.
The CDN supports disabling caching. (A small number can still work without disabling it.)
The CDN allows POST and GET methods.

All three requirements must be met. Otherwise, there is no chance!

This article provides a simple review of CDNs that XHTTP can pass through. Please note! It evaluates only CDNs that I have successfully run with XHTTP. The CDNs reviewed in this article all use Free Tier/Pay as you go (usage-based billing); the quality and behavior of some edge nodes may not fully match the descriptions below.

So far, the CDNs that can run XHTTP are as follows:
Cloudflare
AWS CloudFront
Fastly
Bunny
Gcore
Azion
Alibabacloud ESA
Tencentcloud Edge One
Nordic

Readers can also explore CDNs not mentioned in this article. Links are placed at the bottom of the article.

Some review items use a rating system. Ratings range from 1 to 5, with 5 being the highest score.

Cloudflare

Configuration difficulty: 1 ⭐
After adding the domain to Cloudflare and enabling Cloudflare proxying for a DNS record, it is ready to use.
Edge nodes support IPv6.
Edge nodes support IPv6 origin pulls.
QUIC is supported.
XHTTP can pass through directly without additional settings.
Optimization for mainland China: 2 (Speed is relatively poor.)
Does it support preferred IPs: Not very useful; checks are strict, and edge nodes do not follow DNS scheduling.

AWS CloudFront

Configuration difficulty: 2 ⭐⭐
CNAME access can be used.
Edge nodes support IPv6.
Edge nodes support IPv6 origin pulls.
QUIC is supported.
XHTTP cannot pass through directly. You need to create a rule in the Behavior settings in the console to allow all HTTP method types. (It is recommended to ask an AI for help.)
Optimization for mainland China: 5 (Excellent speed)
Does it support preferred IPs: Preferred IPs can be used, and edge nodes follow DNS scheduling. The client can pin an edge IP.
PAY AS YOU GO: 10 million requests + 1 TB outbound traffic per month.

Fastly

Configuration difficulty: 4 ⭐⭐⭐⭐
CNAME access is supported.
Edge nodes support IPv6.
Edge nodes support IPv6 origin pulls.
QUIC is supported.
The configuration is relatively complicated; it is recommended to ask Codex or Grok for help.
XHTTP cannot pass through directly. Edge nodes may also terminate XHTTP connections; increasing the connection lifetime to the maximum in the console can help alleviate this.
Optimization for mainland China: 4 (Good)
European edge nodes have the best speed.
Does it support preferred IPs: Preferred IPs can be used, and edge nodes follow DNS scheduling. The client can pin an edge IP.
A credit card is required for registration. The Free Tier has only 1 million requests + 100 GB of traffic per month. Usage beyond that is billed by volume. (Under intensive use, XHTTP can exhaust the request allowance in fewer than 10 days.)

Bunny

Configuration difficulty: 1 ⭐
CNAME access is supported.
Edge nodes support IPv6.
Some edge nodes do not support IPv6 origin pulls.
QUIC is supported.
XHTTP can pass through directly after caching is disabled.
Optimization for mainland China: 3 (Average)
Does it support preferred IPs: Preferred IPs can be used, and edge nodes follow DNS scheduling. The client can pin an edge IP.
Edge nodes may terminate XHTTP video streams. Console adjustments cannot effectively improve this. Only 1080P video can be watched.
14-day free trial.
Minimum monthly spend of 1 USD.

Gcore

Configuration difficulty: 2 ⭐⭐
CNAME access is supported.
Edge nodes support IPv6.
Edge nodes do not support IPv6 origin pulls or IPv6 origin servers.
QUIC is supported.
XHTTP cannot pass through directly. It can pass through after allowing all HTTP methods and disabling caching in the console.
Optimization for mainland China: 4 (Good)
Does it support preferred IPs: Preferred IPs can be used on the PAYG Plan, and edge nodes follow DNS scheduling. The client can pin an edge IP.
10 million requests + 2 TB outbound traffic per month. Usage beyond that is billed by volume.

Azion

Configuration difficulty: 5 ⭐⭐⭐⭐⭐
CNAME access is supported.
Edge nodes do not support IPv6.
Edge nodes support IPv6 origin pulls.
QUIC is not supported.
XHTTP cannot pass through directly and requires additional rules. It is relatively complicated; it is recommended to ask an AI for help.
Optimization for mainland China: 2 (Relatively poor)
Does it support preferred IPs: Preferred IPs can be used, and edge nodes follow DNS scheduling. The client can pin an edge IP.
Edge nodes directly terminate XHTTP connections, making video playback impossible. There are currently no console settings that can effectively improve this. Usability is relatively low. Web pages and downloads work normally.
10 million requests + 1 TB outbound traffic per month.
A Pro plan is required after exceeding the allowance.

Alibabacloud ESA

Configuration difficulty: 3 ⭐⭐⭐
CNAME access is supported. (Subdomains are not supported.)
Edge nodes support IPv6.
Edge nodes support IPv6 origin pulls.
QUIC is supported.
XHTTP can pass through directly after caching is disabled.
Optimization for mainland China: 4 (Good)
Does it support preferred IPs: Preferred IPs can be used, and edge nodes follow DNS scheduling. The client can pin an edge IP.
The free plan has unlimited traffic, with no SLA or connection-availability guarantee.
It is strongly recommended to enable VLESS Encryption to prevent XHTTP characteristics from being exposed.
Registration requires an overseas mobile number.

Tencentcloud Edge One

Configuration difficulty: 2 ⭐⭐
CNAME access is supported. (Subdomains are also not supported.)
Edge nodes support IPv6.
Edge nodes support IPv6 origin pulls.
QUIC is supported.
XHTTP can pass through directly after caching is disabled.
Optimization for mainland China: 3 (Average), performing less well than Alibaba Cloud.
Does it support preferred IPs: Preferred IPs can be used, and edge nodes follow DNS scheduling. The client can pin an edge IP.
The free plan has unlimited traffic, with no SLA or connection-availability guarantee.
You can join the activity to receive a free plan: Share a speed test to unlock more EdgeOne free plans
It is strongly recommended to enable VLESS Encryption to prevent XHTTP characteristics from being exposed.
Registration does not require an overseas mobile number.

Nordic

Configuration difficulty: 3 ⭐⭐⭐
CNAME access is supported.
Edge nodes support IPv6.
Edge nodes support IPv6 origin pulls.
QUIC is supported.
XHTTP can pass through directly after caching is disabled.
Optimization for mainland China: 4 (Good)
Does it support preferred IPs: Preferred IPs can be used, and edge nodes follow DNS scheduling. The client can pin an edge IP.
25 GB of free traffic per month.
It may delete Zones for no apparent reason. Although XHTTP can run, it may be deleted very quickly.
The reason is unknown.

Wedos

Configuration Difficulty: 5 ⭐⭐⭐⭐⭐
Supports CNAME access.
Edge does not support IPv6.
Edge supports IPv6 origin pull. (Origin site allows IPv6 addresses, not yet verified)
Supports QUIC.
Extremely difficult to configure! CDN WAF will directly block XHTTP. All security protections must be turned off! Caching must also be disabled. It is recommended to use AI tools to complete this! Video streams will also be interrupted, but downloads and web browsing are normal. Edge certificate issuance sometimes gets stuck.
Optimization for Mainland China: 3 (General)
Supports preferred IP: Preferred IP is possible; edge is subject to DNS scheduling. The client can hardcode the edge IP. (Only one set of Anycast IPs is actually returned)
Free Tier Unlimited Traffic.
